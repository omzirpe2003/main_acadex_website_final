# Section 1: PROJECT OVERVIEW
ACADEX Technologies is an architectural, trustworthy marketing and management web application for a Smart Class & School Management System SaaS + Hardware product. The platform showcases core educational features (rapid daily attendance, instant WhatsApp alerts to parents, teacher timetable conflict resolution, exam report generation, and turnkey smart classroom hardware setups) and provides direct call-to-actions to book interactive product demos and chat with the Pune systems engineering desk. The demo booking system writes directly to a Supabase database instance.

# Section 3: ROUTING STRUCTURE
The application supports multi-route browsing with in-page anchor navigation:
- `/` - Main Marketing Page
  - `#overview` - Split Diptych Hero with Live Attendance & WhatsApp Terminal Mockup
  - `#features` - Interactive System Modules Workbench (Attendance, Timetable, Exam, WhatsApp)
  - `#how-it-works` - Progressive 4-Step 24-Hour Rollout Pathway
  - `#setups` - Turnkey Hardware Architectures (Studio, Computer Lab, Interactive Smart Classroom)
  - `#demo-form` - Transparent Pricing & Direct Supabase Demo Booking
- `/setup/:type` - Dedicated Hardware Specification Sheets (`/setup/studio`, `/setup/lab`, `/setup/classroom`)

# Section 5: STATE MANAGEMENT
State is managed via React hooks:
- `isDarkMode` (boolean): Controls dark/light mode toggle with localStorage synchronization (`acadex_theme`).
- `isMobileMenuOpen` (boolean): Controls responsive navigation drawer display.
- `activeTab` (string in HomePage): Toggles interactive workbench screen (`attendance`, `timetable`, `exam`, `whatsapp`).
- `formData` (object): Captures and validates demo booking submissions for Supabase insertion.
- `showPopup` (boolean): Displays confirmation modal upon successful booking submission.

# Section 7: PAGES & DATA FLOW
### Route: `/` (Main App)
- **Data Reads**: None
- **Data Writes**: `demo_bookings` table in Supabase via BookDemo form submission.
- **Components Composed**: `Header`, `HeroSplitDiptych`, `InteractiveWorkbench`, `HowItWorks`, `HardwareArchitectures`, `DemoBookingSection`, `Footer`.
- **Loading/Error/Realtime**: The Book Demo submission form handles pending loading state and shows an interactive custom confirmation modal on success, or an inline error banner on failure.

### Route: `/setup/:type` (Hardware Details)
- **Data Reads**: Local technical specifications dictionary (`setupContent`).
- **Data Writes**: Client-side consultation quote request logging.

# Section 8: FORMS & VALIDATION
### Book Demo Form
- **Form Fields**:
  1. `instituteName` (text, required)
  2. `fullName` (text, required)
  3. `email` (email, required)
  4. `mobile` (tel, required, verified to contain at least 10 numeric digits)
  5. `institutionSize` (select dropdown)
- **Validation logic**: Client-side required field checks and regex digit counting on telephone input (`/\D/g`).
- **Submission Destination**: `demo_bookings` table on Supabase.

# Section 9: AUTH UI LAYER
No authentication user interface is present on this marketing website. The book demo submission uses the public anon role via Supabase Client under RLS policies. External login link redirects to the secure portal.
